# Sicherheitslücken melden

Bitte melde Sicherheitslücken oder Datenschutzprobleme **nicht** als öffentliches Issue.

Schreib stattdessen eine E-Mail an die Adresse im [Impressum](https://playwithfun.de/impressum.html) –
am besten mit einer kurzen Beschreibung, wie sich das Problem nachstellen lässt.
Wir melden uns so schnell wie möglich.
