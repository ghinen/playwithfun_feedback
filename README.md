# 🎉 PlayWithFun – Feedback & Hilfe

Hier sammeln wir Fehlermeldungen, Ideen und Fragenvorschläge für
**[PlayWithFun](https://playwithfun.de/)** – kostenlose Partyspiele im Browser, ohne Anmeldung.

| Ich möchte … | |
| --- | --- |
| 🐞 einen Fehler melden | [Fehler melden](https://github.com/ghinen/playwithfun_feedback/issues/new?template=bug_report.yml) |
| 💡 eine Idee / ein neues Spiel vorschlagen | [Idee vorschlagen](https://github.com/ghinen/playwithfun_feedback/issues/new?template=feature_request.yml) |
| 📝 neue Fragen einreichen | [Fragen einreichen](https://github.com/ghinen/playwithfun_feedback/issues/new?template=question_suggestion.yml) |
| 📖 Hilfe & Antworten auf häufige Fragen | [Wiki](https://github.com/ghinen/playwithfun_feedback/wiki) |
| 🔒 eine Sicherheitslücke melden | per E-Mail, siehe [SECURITY.md](SECURITY.md) |

## Gut zu wissen

- Für Meldungen brauchst du ein (kostenloses) GitHub-Konto.
- **Alle Meldungen sind öffentlich.** Bitte keine persönlichen Daten, echten Namen von Mitspielern
  oder Chatverläufe ohne Einverständnis posten.
- Gibt es deinen Vorschlag schon? Dann reagiere lieber mit 👍 auf das bestehende Issue –
  so sehen wir, was am meisten gewünscht wird.
